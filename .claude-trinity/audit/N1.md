## 删了什么

### C1 `service/funding_source.go`
- 删 `FundingSource` 接口本身（只剩一个实现，按契约内联掉抽象层）
- 删 `SubscriptionFunding` struct 与 4 个方法（`Source` / `PreConsume` / `Settle` / `Refund`）
- 删 `refundWithRetry()`（唯一调用方是 `SubscriptionFunding.Refund`，随之成为死代码）
- 删 `time` import；保留 `WalletFunding` 的 4 个方法与 `Source()` 语义

### C2 `service/billing_session.go`
- `BillingSession.funding` 类型 `FundingSource` → `*WalletFunding`（内联的调用方同步）
- 删字段 `extraReserved`（唯一读者是订阅退款与订阅 syncRelayInfo）
- `Settle()`：删 `SubscriptionPostDelta` 累加
- `Refund()`：删订阅 `PostConsumeUserSubscriptionDelta` 补退分支
- `needsRefundLocked()`：删 `*SubscriptionFunding` 断言分支 → `return s.tokenConsumed > 0`
- `preConsume()`：删 `no active subscription` / `subscription quota insufficient` 字符串匹配分支（连同其上的 TODO 注释）；`strings` import 随之移除
- `reserveFunding()` / `rollbackFundingReserve()`：类型 switch → 直连钱包，同时消掉 `default: unsupported funding source` 死分支
- `shouldTrust()`：删 `switch s.funding.Source()`，直接 `return s.relayInfo.UserQuota > trustQuota`
  —— **订阅信任旁路禁用逻辑已按契约删除，旁路对钱包恢复生效，是预期行为**
- `syncRelayInfo()`：只剩 `FinalPreConsumedQuota`
- `NewBillingSession()`：删 `pref` 归一化、`trySubscription()` 闭包、四路 `switch pref`，钱包逻辑由闭包内联为函数体（33 行）

### C3 `service/quota.go`
- `PostConsumeQuota()`：删订阅分支，`DecreaseUserQuota` / `IncreaseUserQuota` 成为唯一扣费路径
- 删 `checkAndSendSubscriptionQuotaNotify()`（整函数，文件末尾）

### C4 `service/billing.go`
- const 块 → 单常量 `BillingSourceWallet = "wallet"`，删 `BillingSourceSubscription`
- `SettleBilling()`：删「订阅走订阅预警 / 否则走钱包预警」二选一，只留 `checkAndSendQuotaNotify`

### C5 `service/log_info_generate.go`
- `appendBillingInfo()` 删 9 个订阅 key：`subscription_id` / `subscription_pre_consumed` /
  `subscription_post_delta` / `subscription_plan_id` / `subscription_plan_title` /
  `subscription_total` / `subscription_used` / `subscription_remain` / `subscription_consumed`
- 附带删 `wallet_quota_deducted`（仅在订阅分支内写入）与 `billing_preference`（依赖已删的 `UserSetting.BillingPreference`）
- **保留 `other["billing_source"]`，恒为 `BillingSourceWallet`**（历史日志解析端依赖）
